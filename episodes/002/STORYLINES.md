# EP002 — 스토리라인 3안 (HyperFrames story.md §2, 2026-11-06)

공통 전제: 대본·음성 확정(4.5분, Kokoro am_michael 1.26배), 16:9 1920×1080 30fps, 2D, 생성형 이미지·영상 0, 음악·효과음은 무료 로컬 합성. 숫자는 `02_research.md`에서만, 하나의 데이터 모듈(NY Fed CSV)이 모든 그림을 움직인다.

## A. 출발 안내판 (추천 — 이 영상의 사실 자체가 "73개 전공의 순위표"이고, 기둥마다 그 순위표를 다시 정렬하는 이야기라서)
- 장치·형식: **숫자가 떨어진다 + 하나의 화면이 계속 재배열된다.** 공항 출발 안내판(스플릿 플랩) 하나에 73개 전공이 줄지어 있고, 내레이션이 기준을 바꿀 때마다 판이 촤르륵 넘어가며 다시 정렬된다. 시청자는 "우리 애 전공이 어디로 가나"를 눈으로 쫓는다.
- 첫 2초: 검은 안내판의 플랩이 "COMPUTER SCIENCE … ON TIME"을 띄웠다가, 상태 칸만 촤르륵 넘어가 "DELAYED"로 바뀐다.
- 비트: 훅(ON TIME → DELAYED) → 실업률로 정렬, CE 2위·CS 4위 → 공학 계열만 남기고 나머지 접힘(전기 3.2·기계 4.4) → 스탠퍼드 15→19% 게이트 표시 → 하향 취업으로 재정렬(CS가 아래로) → 초봉으로 재정렬(CS가 위로) → BLS 전망 칸 "PROJECTION" → 판이 두 축으로 접혀 산점도 → "첫 직장 계획" 한 줄 → 엔드카드.
- 룩: 무광 검은 안내판, 노란 플랩 글자(실물 플랩의 이음선과 그림자), 바탕은 공항 대합실 벽의 따뜻한 회색. 강조색은 플랩 하나에만 빨강.
- 소리: 재정렬마다 플랩 넘김 소리(합성), 낮은 대합실 공간음, 음악은 잔잔한 펄스.

## B. 부엌 식탁의 등록금 고지서
- 장치·형식: **누군가의 하루 한 장면 + 물체에서 물체로 이어지는 연쇄.** 부모가 식탁에서 등록금 고지서를 연다. 고지서 항목 줄이 막대가 되고, 막대가 냉장고 자석 순위표가 되고, 자석이 달력 위 첫 출근일이 된다.
- 첫 2초: 식탁 위 봉투에서 고지서가 미끄러져 나오고 "TUITION DUE"에 형광펜이 그어진다.
- 비트: 고지서 → 항목 줄이 전공 막대로 → 냉장고 자석 순위(CE 2·CS 4) → 형제 전공 자석(전기·기계) → 채용 공고 전단이 줄어듦(스탠퍼드) → 급여명세서(초봉 $87k) → 달력에 "PROJECTION" 스티커 → 식탁 위 두 축 산점도 → 고지서 뒷면에 "첫 직장 계획?" → 엔드카드.
- 룩: 위에서 내려다본 원목 식탁, 실제 종이 질감의 평면 일러스트(손그림 아님, 벡터), 형광 노랑 하나.
- 소리: 봉투·종이·자석 딸깍, 부엌 공간음, 어쿠스틱 기타 루프.

## C. 캠퍼스 지도 비행 (과감한 안)
- 장치·형식: **물체가 곧 설명 + 한 세계를 날아다니기.** 평면 등각 캠퍼스 지도에서 건물 하나가 전공 하나, 건물 높이가 실업률이다. 카메라가 캠퍼스 위를 날며 건물이 솟고 내려앉는다.
- 첫 2초: 위에서 본 캠퍼스, 한가운데 "COMPUTER SCIENCE" 건물만 갑자기 솟아오르고 그림자가 나머지를 덮는다.
- 비트: 캠퍼스 전경 → 73개 건물 높이 = 실업률, CE·CS가 최상위 → 공학관 구역으로 줌(전기·기계 낮음) → 정문 채용 게시판이 비어 감(스탠퍼드) → 건물 색 = 하향 취업으로 바뀜 → 건물 위 깃발 높이 = 초봉 → 지평선 너머 "PROJECTION" 건설 크레인 → 지도가 기울며 두 축 산점도로 평평해짐 → 엔드카드.
- 룩: 낮 햇빛의 등각 지도, 단색 블록 건물, 그림자 하나의 방향, 강조색은 CS 건물 하나.
- 소리: 바람·새소리 앰비언스, 건물이 솟을 때 둔탁한 붐, 미니멀 피아노.

> 차이: A는 "한 화면이 계속 재정렬"(순위가 주인공), B는 "부모의 하루"(사람이 주인공), C는 "지도 위 비행"(공간이 주인공). 셋 다 EP001(3D 책상·종이 소품·고정 카메라)과 장치가 다르다.
