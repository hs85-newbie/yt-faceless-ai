# 채널 목소리 (대본 작성 기준)

`/yt-script`는 원래 `~/.claude/youtube/voice.md`를 읽지만, 이 채널은 사람 목소리 원본이 없어 여기서 정의한다.

- 화자: 차분하고 건조한 해설자. 데이터를 따라가는 탐정 톤. 흥분하지 않는다.
- 시청자: 20~30대 영어권 사무직·취준생과 그 부모. 경제 용어는 처음 나올 때 한 문장으로 푼다.
- 쓰지 않는 말: insane, shocking, mind-blowing, "you won't believe", "smash that like button", "in today's video".
- 숫자는 리서치 문서에 출처가 있는 것만. 저자가 추정이라 한 값은 "an estimate"라고 말한다.
- 결론을 과장하지 않는다. 연구가 "can explain"이라 하면 "explains"로 바꾸지 않는다.
- 구독 요청은 하지 않는다. 끝은 질문 하나.
- 분당 150단어 기준으로 쓴다.
