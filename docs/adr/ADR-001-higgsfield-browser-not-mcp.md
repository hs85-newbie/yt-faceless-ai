# ADR-001 힉스필드는 MCP가 아니라 브라우저로 쓴다

- 날짜: 2026-10-24
- 상태: 확정

## 배경
힉스필드 공식 요금 페이지: "요금제에 포함된 무제한 모델과 무료 생성은 higgsfield.ai에서만 이용할 수 있으며 MCP/CLI, Canvas 또는 Supercomputer에서는 이용할 수 없어요."

## 결정
Claude in Chrome으로 웹 화면을 조작해 클립을 만든다. 로그인이 필요하므로 agent-browser가 아니라 Claude in Chrome을 쓴다. 유튜브 전용 크롬 프로필을 만들고 deviceId로 고정한다.

## 결과
- Plus(월 59달러) 무제한 모델 혜택을 자동화에서도 받는다.
- 생성은 비동기(수 분)라 사람 속도로 대기·다운로드하는 흐름이 된다.
- 미확인: 힉스필드 이용약관의 자동화 조항. 결제 전 확인.
